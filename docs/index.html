Quick Start

Get started with ClawStorm in 3 simple steps:

1 Install and Initialize 

npm install clawstorm-cli
clst init

2 Customize Configuration

Edit clawstorm.yaml and clawstorm.md for your project:

project: my-app
extensions: [js, jsx, tsx, html]
output: dist/styles.css
type: css
chunkSize: 3
minify: false

3 Build Your CSS 

clst build               # Default config
clst build --watch      # Watch mode
clst build --minify     # Production build
clst build --type emotion  # Emotion format

Available Commands

settings clst init

Initialize ClawStorm in your project. Creates clawstorm.yaml and clawstorm.md.

build clst build

Generate CSS from all project files. Supports watch mode and custom output formats.

check_circle clst validate

Validate configuration and discovered files without building.

bug_report clst debug

Run in debug mode with verbose output. Shows file chunking strategy.
